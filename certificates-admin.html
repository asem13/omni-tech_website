اختار ملف الإكسيل اللي ملّيته، والأسماء هتتضاف للسجل. هنجيب الشهادات المنشورة تلقائيًا للحفاظ على الأشخاص الموجودين؛ مش محتاج تختار ملف JSON الأول.

تنزيل قالب Excel الفارغ

املأ ورقة «الشهادات» من الصف الثاني دون تغيير العناوين. الاسم ورقم الشهادة مطلوبان؛ الدورة والتاريخ اختياريان. التاريخ بصيغة YYYY-MM-DD. الحد الأقصى 10000 صف و10 ميجابايت.

بعد إضافة الأسماء

راجع الأسماء ثم اضغط «تنزيل ملف الشهادات» أسفل الصفحة. ارفع الملف الناتج certificates.json مكان القديم على GitHub لنشر التحديث. الصفحة بتحوّل Excel تلقائيًا؛ مش محتاج تكتب أو تعدّل JSON بنفسك.

خيارات إضافية: تحميل السجل أو استيراد نسخة احتياطية

Excel يضيف إلى السجل الحالي، بينما استيراد JSON يستبدل النسخة الحالية. استخدم «بدء سجل فارغ» لأول استخدام فقط؛ نشره بدل سجل موجود يحذف بياناته القديمة.

هذه أداة لتحرير الملف. النشر يتطلب صلاحية حسابك على GitHub، وملف السجل المنشور متاح للعامة.
