# إدارة شهادات OmniTech

## إضافة أشخاص من Excel

1. افتح صفحة الإدارة واضغط «تنزيل قالب Excel الفارغ» (`certificates-template.xlsx`).
2. املأ ورقة «الشهادات» من الصف الثاني. الأعمدة بالترتيب: اسم صاحب الشهادة، رقم الشهادة، اسم الدورة، تاريخ الإصدار. أول عمودين مطلوبان، والآخران اختياريان. لا تغيّر صف العناوين.
3. عمود رقم الشهادة مُنسّق كنص لحماية الأصفار في البداية والأرقام الطويلة. حافظ على تنسيق النص، ولا تستخدم معادلات. استخدم تاريخ Excel أو تاريخًا نصيًا بصيغة `YYYY-MM-DD`.
4. في أول صفحة الإدارة، اختر ملفك من «ارفع ملف Excel هنا». يُجلب السجل المنشور تلقائيًا قبل الإضافة دون اختيار JSON. إذا تعذّر الجلب لن تتغير البيانات؛ يمكنك إعادة المحاولة، أو لأول استخدام فقط فتح «خيارات إضافية» وبدء سجل فارغ.
5. الاستيراد يضيف الشهادات إلى السجل الحالي. يُتجاهل السجل المطابق الموجود بالفعل. الرقم الموجود ببيانات مختلفة أو الرقم المكرر داخل Excel يمنع استيراد الملف بالكامل مع رسالة توضح المشكلة. لا تُحذف الشهادات القديمة.
6. راجع البيانات ثم نزّل `certificates.json` وارفعه إلى GitHub كالعادة. رفع Excel وحده على GitHub لا ينشر الشهادات.

يدعم الاستيراد `.xlsx` بحد أقصى 10000 صف بيانات و10 ميجابايت، ويتجاهل الصفوف الفارغة. القالب يحتوي على 1000 صف مجهّز ويمكن إضافة صفوف أخرى بنفس التنسيق. لتحديث الموقع بهذه الميزة، ارفع `certificates-admin.html` و`certificates-admin.js` و`certificates-excel.js` و`certificates-template.xlsx` ومجلد `vendor` كاملًا. لا تستبدل ملف بياناتك المنشور `certificates.json` بالنسخة الفارغة المحلية.

قارئ Excel: SheetJS CE 0.20.3، نسخة محلية من [المصدر الرسمي](https://docs.sheetjs.com/docs/getting-started/installation/standalone/). الترخيص موجود في `vendor/sheetjs-LICENSE.txt`. لا تُرسل ملفات Excel إلى خدمة خارجية.

صفحة الزائر: `verify.html` — اكتب رقم الشهادة ليظهر الاسم وبياناتها إن كان الرقم مسجلًا.

صفحة الإدارة: `certificates-admin.html` — أداة لتحرير ملف JSON، وليست لوحة دخول أو حفظ مباشر على السيرفر.

## الاستخدام لأول مرة

1. افتح `certificates-admin.html` في المتصفح، ثم اختر «بدء سجل فارغ». السجل المرفق فارغ عمدًا ولا يحتوي شهادات تجريبية.
2. اكتب الاسم ورقم الشهادة. اسم الدورة وتاريخ الإصدار اختياريان.
3. اضغط «إضافة الشهادة»، وكرر لكل شخص. كل شهادة تحتاج رقمًا فريدًا؛ يُفضّل رقم غير متسلسل يصعب تخمينه.
4. اضغط «تنزيل ملف الشهادات» واحتفظ بالملف باسم `certificates.json` تمامًا (احذف لاحقة مثل `(1)` إذا أضافها المتصفح).
5. ارفع ملفات الميزة مع الموقع، واستبدل `certificates.json` في نفس مجلد `index.html` بالنسخة التي نزلتها. احفظ التغيير في GitHub وانتظر اكتمال GitHub Pages أو نظام النشر الخاص بك.
6. افتح `verify.html` من رابط الموقع، وجرّب رقمًا مسجلًا ورقمًا غير موجود.

## تعديل سجل موجود

حمّل السجل المنشور من صفحة الإدارة على الموقع، أو استورد آخر `certificates.json` محفوظ لديك. أضف وعدّل واحذف، ثم نزّل وارفع الملف كاملًا مجددًا. لا تبدأ سجلًا فارغًا عند إضافة أشخاص جدد إلى سجل موجود، حتى لا تضيع الشهادات السابقة. احتفظ بنسخة احتياطية قبل الاستبدال، وتجنب تعديل نسختين من السجل بالتزامن.

يمكن تشغيل أداة الإدارة مباشرة من الجهاز واستيراد وتصدير الملفات دون سيرفر. صفحة التحقق وزر تحميل السجل يحتاجان تشغيل الموقع عبر HTTP/HTTPS، لأن المتصفحات تمنع عادة قراءة JSON عبر `file://`.

التعديل أثناء فتح الصفحة لا يغيّر الموقع المنشور. لا تُحفظ البيانات تلقائيًا بعد إغلاق الصفحة؛ نزّل الملف أولًا. نشر التغييرات محمي بصلاحيات حساب GitHub، وليس بكلمة مرور داخل JavaScript. يمكن إبقاء ملفَي `certificates-admin.html` و`certificates-admin.js` على جهازك فقط، دون رفعهما، مع إبقاء ملفات CSS وcore بجوارهما محليًا.

## البيانات العامة

`certificates.json` ملف عام يمكن تنزيله كاملًا، حتى لو صفحة التحقق تعرض نتيجة رقم واحد فقط. أضف أسماء وبيانات شهادات مسموحًا بنشرها، ولا تضف هواتف أو بريدًا أو بيانات حساسة. إخفاء القائمة بالكامل عن الزوار يتطلب لاحقًا قاعدة بيانات وواجهة خلفية.

الأرقام تُحفظ كنصوص للحفاظ على الأصفار في البداية. البحث يتجاهل حالة الحروف والمسافات الخارجية، ويحوّل الأرقام العربية والفارسية إلى الإنجليزية؛ الشرطات والمسافات الداخلية جزء من رقم الشهادة. الأرقام المكررة تُرفض. الحذف يجعل الشهادة غير موجودة بعد نشر الملف الجديد.

صيغة الملف:

```json
{"version":1,"certificates":[{"id":"OMNI-2026-001","name":"اسم صاحب الشهادة","course":"اسم الدورة","date":"2026-11-25"}]}
```

الملفات العامة المطلوبة: `verify.html`, `verify.js`, `certificates-core.js`, `certificates.css`, `certificates.json` والشعار الموجود `logo_cropped.jpg`، مع تحديث `index.html` لإظهار رابط التحقق.
