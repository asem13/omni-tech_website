# إدارة الشهادات محليًا

صفحة الإدارة موجودة داخل local-admin فقط. افتح local-admin/certificates-admin.html بالنقر المزدوج. لا تحتاج يوزر أو باسورد؛ الوصول إلى جهازك هو الذي يحمي الأداة.

## الاستخدام
1. احفظ أحدث certificates.json من https://www.omni-tech.courses/certificates.json على جهازك (حفظ باسم).
2. في الإدارة اضغط «اختيار آخر ملف شهادات محفوظ» واختر ملف JSON الذي حفظته.
3. أضف الشهادات يدويًا أو ارفع Excel. القالب موجود داخل local-admin.
4. نزّل certificates.json بعد التعديل، ثم ارفع هذا الملف وحده مكان الملف القديم في GitHub.
5. احتفظ بنسخة احتياطية قبل الاستبدال. لا تستخدم السجل الفارغ الموجود في ملفات المشروع بدل بيانات موقعك.

## خطوة مطلوبة لإزالة الإدارة من الموقع الحالي
التغييرات المحلية لا تحذف الملفات المنشورة تلقائيًا. من مستودع GitHub احذف:
- certificates-admin.html
- certificates-admin.js
- certificates-excel.js
- certificates-template.xlsx
- مجلد outputs إن كان منشورًا: يحتوي على نسخ قديمة من الإدارة.
- مجلد local-admin إن سبق رفعه بالخطأ.

احفظ الحذف وانتظر انتهاء نشر GitHub Pages، ثم تحقق أن الرابط القديم certificates-admin.html لا يفتح الإدارة (يرجع 404). لا ترفع local-admin أو outputs مطلقًا، حتى عند الرفع اليدوي. ملف .gitignore يمنع إضافة نسخ جديدة باستخدام Git فقط؛ لا يحذف الملفات المتتبعة أو المنشورة سابقًا ولا يحمي الرفع اليدوي.

أبقِ verify.html وverify.js وcertificates-core.js وcertificates.css وcertificates.json والشعار على الموقع. صفحة التحقق تعمل كالمعتاد. ملف certificates.json يظل عامًا كما كان؛ هذا الإجراء يزيل واجهة الإدارة فقط. نشر تعديلات البيانات يتطلب صلاحية حساب GitHub.
